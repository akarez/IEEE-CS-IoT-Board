# IEEE-CS IoT Sensor Board

<br>

The IEEE-CS IoT Sensor Board is an ESP32-C3 based development board for the IEEE-CS USF student organization, made for firmware, hardware, and IoT design workshops.
I am currently working on the second version, feature packed with even more sensors and a battery charging circuit.
